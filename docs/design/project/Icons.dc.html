Weather icons

One icon per OpenWeatherMap icon code. The API's code (for example 10d) is used as-is to pick the icon; an unknown code shows 03d. As on OpenWeatherMap, only clear, few clouds and rain look different at night.

Sizes used in the app
64 px · current conditions
32 px · 5-day rows
28 px · Day table
Strokes get slightly thicker at small sizes so the outline stays visible.
